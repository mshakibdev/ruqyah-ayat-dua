# পাইপলাইন — প্রোটোকল PDF থেকে সংকলন JSON

মূল PDF-গুলোর **আরবি টেক্সট লেয়ার ভাঙা** (অক্ষর ও যের-যবর উল্টে আসে) আর
**বাংলায় শব্দের ভেতরে ফাঁক** ঢুকে যায় ("নিয় ত" = "নিয়ত")। তাই:

| অংশ | কোথা থেকে আসে |
|---|---|
| আয়াতের আরবি | উসমানী হাফস মুসহাফ — `hafs.json` |
| আয়াতের বাংলা অর্থ | মুহিউদ্দীন খানের অনুবাদ — `bn-mkhan.json` |
| পাঠসংখ্যা | PDF (সংখ্যা ভাঙে না) |
| নিয়ত | PDF, তারপর `niyat_fix.json`-এ হাতে মিলিয়ে নেওয়া পাঠ |
| দোয়ার আরবি | পাতার ছবি দেখে হাতে — `assemble.py`-তে |

## তথ্যভাণ্ডার নামানো

রিপো হালকা রাখতে বড় দুটি ফাইল এখানে রাখা হয়নি:

```bash
pip download --no-deps -d /tmp/q quran-text
unzip -o /tmp/q/quran_text-*.whl -d /tmp/qx
cp /tmp/qx/quran_text_data/hafs.json .

curl -o bn-mkhan.json \
  https://raw.githubusercontent.com/fawazahmed0/quran-api/1/editions/ben-muhiuddinkhan.json
```

## চালানো

```bash
python3 extract_protocol.py <নথি>.pdf > ../draft/<নাম>.json   # আয়াত বের করা
python3 assemble.py                                            # সংকলন JSON বানানো
cd .. && python3 gen_ayat_app.py                               # পাতা তৈরি
```

`despace.py` — PDF-এর বাংলা থেকে ভুল ফাঁক সরায়। সিদ্ধান্ত নেয় শব্দের
**কম্পাঙ্ক** দেখে: "সু" অনুবাদে দু-একবার এলেও শব্দ নয়, তাই "সু রক্ষা" জোড়া লাগে;
"সাড়া" ও "দেওয়া" দুটোই পাকা শব্দ, তাই ওদের ফাঁক থাকে।

## `jinn/` — জিন ও নজর ব্যাচ (হেরেডিটারি, মারিদ, ডানাওয়ালা, মাথার বদনজর, মাথার ওয়াসওয়াসা)

একই পাইপলাইন, একই ভাঙা টেক্সট লেয়ার। চালানোর ক্রম:

```bash
python3 extract_protocol.py   # PDF → draft/*.json  (আরবি হাফস মুসহাফ থেকে, অর্থ মুহিউদ্দীন খান)
python3 assemble.py           # draft + হাতে পড়া দোয়া → ../../<key>.json
```

`assemble.py` উপরের ফোল্ডারের `assemble.py` থেকেই `OPEN` / `CLOSE_DUA` / `CLOSE_Q`
আমদানি করে — শুরুর ও সমাপ্তির অংশ দশটি প্রোটোকলে অভিন্ন।

- `cnt_fix.json` — যে কার্ডের পাঠসংখ্যা বা নিয়ত পরের পাতায় গড়িয়ে গেছে, অথবা
  যুক্তাক্ষরে কেটে গেছে (`অন্তত ৭ বার` → `অন্`), সেগুলো পাতার ছবি দেখে মিলানো।
  চাবি `stem|surah|first`। সব চাবি না মিললে `assemble.py` থেমে যাবে।
- বিশেষ দোয়াগুলোর আরবি ও বাংলা পাতার ছবি দেখে হাতে তোলা — টেক্সট লেয়ার থেকে নয়।

## `ruqsrc3/` — তৃতীয় ব্যাচ (তাহরীজ, জিনের দখলদারি, জিন চালান, কারিন ও ওয়াসওয়াসা, স্বপ্ন, বিচ্ছেদের সিহর, চুল পড়া)

একই পাইপলাইন। চালানোর ক্রম PDF-গুলোর পাশে রেখে:

```bash
python3 extract_protocol.py <file>.pdf > draft/<stem>.json   # প্রতিটির জন্য
python3 assemble.py                                          # → ../../<key>.json
```

- শুরুর দোয়া (৩/১৯/৩) ও সমাপ্তির ব্লক দশটি নয়, **সতেরোটি** প্রোটোকলেই অভিন্ন —
  `newsrc/assemble.py` থেকেই আমদানি করা হয়।
- বিশেষ দোয়ার আরবি, বাংলা ও পাঠসংখ্যা পাতার ছবি দেখে হাতে তোলা, টেক্সট লেয়ার থেকে নয়।
  তাহরীজের দীর্ঘ অনুচ্ছেদটি উৎসের নিজের অনুরোধে ১৭০ dpi-তে আবার মিলিয়ে দেখা হয়েছে।
- `cnt_fix.json` — আট কার্ডের পাঠসংখ্যা ও নিয়ত পরের পাতায় গড়িয়ে গিয়েছিল।
